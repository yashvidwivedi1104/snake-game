# 🐍 Classic Snake Game in Java

A desktop-based classic Snake Game developed using **Java Swing** and **AWT**. The game features smooth grid-based movement, dynamic apple generation, collision mechanics, and a real-time score tracker.

## 🚀 Features
* **Grid-Based Movement:** Smooth directional controls using keyboard key events (`UP`, `DOWN`, `LEFT`, `RIGHT`).
* **Collision Detection:** Automatically triggers a "Game Over" state if the snake hits the window boundaries or crashes into its own body.
* **Score System:** Dynamically calculates and displays the score based on the number of apples eaten.
* **Custom Assets:** Renders custom graphics for the snake's head, body segments, and apples loaded from local resources.

## 🛠️ Tech Stack
* **Language:** Java
* **Framework / Libraries:** Java Swing (`JPanel`, `Timer`), AWT (`Graphics`, `Image`, `KeyAdapter`)
